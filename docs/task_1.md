# Task 1 — Understand Social Media Workflow

## Objective

The objective of this task is to understand how a **social media platform works in the real world** before starting development.

Before building features such as posts, likes, and comments, it is important to understand how users interact with the platform and how information flows through the system.

This task focuses on analyzing the **core workflow of a social media application** and identifying the components required to implement it.

---

# What is a Social Media Platform

A social media platform is an online system that allows people to **create, share, and interact with content**.

Users can create posts, interact with posts created by others, and build connections with people through shared information and discussions.

Examples of social media platforms include systems where users can:

* Share thoughts or updates
* Upload content
* Interact with other users
* Participate in discussions
* Follow platform activity through a feed

The most important element of a social media platform is **user-generated content**.

---

# Why People Use Social Media Platforms

People use social media platforms for multiple reasons.

Some common motivations include:

* Sharing personal updates
* Communicating with friends and communities
* Discovering new information
* Expressing opinions
* Engaging in discussions
* Building online identity

For developers, understanding these motivations helps in designing systems that support user interaction effectively.

---

# Core Components of a Social Media Platform

A social media system usually consists of several key components.

These include:

User accounts
User profiles
Posts
Feed system
Likes
Comments
Moderation tools

Each component supports a specific interaction between users and the platform.

---

# Social Media Interaction Flow

A simplified interaction flow of the ConnectX platform is shown below.

User → Register → Login → Create Post → Feed Display → Like / Comment

Explanation of the flow:

1. A user creates an account on the platform.
2. The user logs into the system.
3. The user creates a post.
4. The post appears in the feed.
5. Other users can interact with the post.
6. Interactions include liking or commenting on the post.
7. Administrators monitor activity and moderate inappropriate content.

This flow defines how information moves through the system.

---

# Example User Scenario

Consider the following example scenario:

1. Alice creates an account on the platform.
2. Alice logs in and writes a post.
3. Bob logs into the platform and sees Alice’s post in his feed.
4. Bob likes the post and adds a comment.
5. The system records the interaction and updates the post engagement data.

This interaction demonstrates the basic social engagement cycle.

---

# Common Problems in Unmanaged Social Platforms

If a social media system does not include moderation or proper rules, several issues may occur.

Examples include:

* Spam posts
* Abusive comments
* Fake accounts
* Harmful or inappropriate content
* Platform misuse

To address these issues, the system must include administrative controls such as:

* content moderation
* user blocking
* platform monitoring
